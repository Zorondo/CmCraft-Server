# Описание проекта

Проект представляет собой многорежимный Minecraft-сервер с акцентом на соревновательные PvP-игры. Основные игровые направления — **SkyWars** и **BedWars**, реализованные на базе SkyWarsReloaded и Screaming BebWars.

# Установка

Запустить `install.sh` и выбрать скачать все. Скрипт автоматически скачает необходимые файлы для запуска и обновит файлы с репозитория.

## Альтернативная установка

Перейти в деректорию `bash_scripts` и вручную запустить через консоль bash скрипты.
