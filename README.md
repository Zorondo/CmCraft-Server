# Описание проекта

Проект представляет собой многорежимный Minecraft-сервер с акцентом на соревновательные PvP-игры. Основные игровые направления — **SkyWars** и **BedWars**, реализованные на базе специализированных плагинов.

# Установка

Запустить `install.py` и выбрать скачать все. Скрипт автоматически скачает необходимые файлы для запуска и обновит файлы с репозитория.

## Альтернативная установка

Перейти в деректоорию `bash_scripts` и вручную запустить через консоль bash скрипты.

## Карты для мини игр

[Скачать архив](https://drive.google.com/file/d/1vL8ZkciMlTLhJU6wB8cWPP4V5RGBtF5G/view?usp=sharing "Ссылка на архив") и перенести содержимое `BedWars` и папку `world` перенести в папку сервера. Содежимое SkyWars перенести в `plugins/Skywars/maps`
